# EcoClassify

Sistema de clasificación de residuos con **Python, Flask y TensorFlow/Keras**.
Identifica automáticamente el tipo de residuo a partir de una imagen usando un
modelo de red neuronal entrenado con Keras.

## Características

- Clasificación de residuos mediante visión por computadora.
- API web ligera con Flask.
- Dos modelos entrenados: `modelo.keras` y `modelo_basura_alta_precision.keras`.
- Fácil de ejecutar localmente.
